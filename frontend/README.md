# Cup2Eat

A responsive React and Vite website concept for Cup2Eat's edible-cup brand.

## Run locally

```sh
npm install
npm run dev
```

## Content and demo scope

The edible-cup concept and headline reflect the supplied brand brief. The
flavour names, ingredients, allergens, nutritional details, sizes, pricing,
storage guidance, beverage compatibility, hold time, and product photography
were not provided, so the site does not make up those details. The cup artwork
is an original illustration for this concept, not a photograph or a verified
Cup2Eat product image.

The business enquiry form performs browser-side required-field validation but
does not transmit or store information. Instagram buttons link to
[@cup2eat](https://www.instagram.com/cup2eat/); the profile itself is not
embedded in the page. A WhatsApp number and other contact details were not
provided.

This frontend is a static UI demo. It does not include an API, database,
authentication, admin dashboard, payments, order management, analytics, or
working enquiry/newsletter delivery.
